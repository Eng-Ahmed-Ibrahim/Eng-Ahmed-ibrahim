## 🚀 Featured Project: POS & Inventory Management System

A full POS and inventory system built with **Laravel + React**.

- FIFO/LIFO batch inventory tracking with accurate returns
- Concurrency-safe transactions (`DB::transaction()` + `lockForUpdate()`)
- Wallet/balance management using a ledger + materialized balance pattern with idempotency keys
- Daily/monthly inventory snapshots via Artisan commands
- Role & permission management (Spatie) with force-logout via Passport token revocation
- Kiosk order management with print retry logic
- React admin dashboard
- Architecture: Service Layer, Repository, Strategy, Factory, Template Method
